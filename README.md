ဤဖိုင်သည် internet မလိုဘဲ browser ထဲတွင် တိုက်ရိုက်ဖွင့်ပြီး အသုံးပြုနိုင်သည်။

2. Purpose

ဤ HTML file ၏ရည်ရွယ်ချက်မှာ ACCA FR / F7 topics များကို textbook ပုံစံတစ်ခုတည်းဖြင့် မဟုတ်ဘဲ visual mind map ပုံစံဖြင့် စနစ်တကျလေ့လာနိုင်ရန် ဖြစ်သည်။

အဓိကအသုံးဝင်သောအချက်များမှာ—

Chapter တစ်ခုချင်းစီကို သီးခြားဖွင့်ကြည့်နိုင်ခြင်း

Formula, rule, example, exam focus, common trap များကို section အလိုက်ကြည့်နိုင်ခြင်း

Arrow နှိပ်မှသာ အသေးစိတ် content များပေါ်လာခြင်း

မလိုအပ်သော AI / robot / voice / mic features မပါခြင်း

Offline browser တွင် အသုံးပြုနိုင်ခြင်း

3. Main Features

3.1 Mind Map Structure

ဖိုင်ထဲတွင် ACCA FR / F7 chapters များကို mind map node ပုံစံဖြင့် ဖော်ပြထားသည်။

Chapter card တစ်ခုကိုနှိပ်ပါက သက်ဆိုင်ရာ chapter view သို့ဝင်နိုင်သည်။

3.2 Chapter-only View

Chapter တစ်ခုကိုနှိပ်ပါက ထို chapter နှင့်သက်ဆိုင်သော content များကိုသာ ဖော်ပြမည်။

ဥပမာ—

Chapter 1 ကိုနှိပ်ပါက Chapter 1 content များသာပေါ်မည်။

← အကုန်ပြန်ကြည့်ရန် ကိုနှိပ်ပါက full mind map view သို့ ပြန်သွားနိုင်သည်။

3.3 Click-to-open Sections

Chapter ထဲသို့ဝင်ပြီးနောက် section များသည် တစ်ခါတည်းမပေါ်ပါ။

အသုံးပြုသူက section arrow ကိုနှိပ်မှသာ အောက်ပါအချက်များပေါ်လာမည်—

Formula / working map

Exam thinking process

Case examples

Common mistakes / exam traps

Exam focus

ဤပုံစံသည် screen မရှုပ်စေရန်နှင့် တစ်ဆင့်ချင်းစီလေ့လာနိုင်ရန် ရည်ရွယ်ထားသည်။
